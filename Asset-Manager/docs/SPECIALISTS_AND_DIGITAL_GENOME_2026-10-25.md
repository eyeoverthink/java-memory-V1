## A real public sequence control

The reference is Arabidopsis thaliana chloroplast rbcL accession U91966.1,
2,187 bases, downloaded with its EMBL annotation from the primary ENA archive.
The package under `data/genomics/references/U91966.1` contains both originals and
transfer provenance. The importer requires the FASTA sequence and annotation
sequence to agree, checks the provider MD5 when present, and archives their hashes.

Before absorption, a blinded sample_A header is unknown. After absorption, the
same sequence matches U91966.1 without using its header. Exact forward and
reverse-complement matching is a closed local-reference operation. A partial or
changed unmatched sequence stays unknown; it is not assigned a guessed species.
An identical gene sequence can be shared across entities, so the result carries
reference annotation rather than an exclusive whole-organism identity claim.

six-base token, versus approximately -8.229748623711724 for a composition-matched
shuffle: difference +4.932681419037202. It scored 2,184 bases and excluded the
three-base tail. This is one positive control, not a held-out identification
benchmark; overlap with training data was not assessed. Carbon's likelihood and
the independent exact-reference result are displayed separately.

Valid A/C/G/T output, model preference and biological function remain distinct

## Recovering actual digital DNA

DigitalGenomeArchive saves canonical JSON bytes and a lossless A/C/G/T encoding,
four symbols per byte, high pair first. Snapshots and manifests are addressed by
SHA256; latest pointers are replaced atomically and prior versions remain.
Identical current payloads deduplicate. Manifests carry the previous manifest
hash. Reading checks the manifest, payload, FASTA and exact byte roundtrip.
This is a software-state format; hashes do not constitute signatures or encryption.

The genomics profile contains its persistent component UUID, evidence identities,
actual registered-brain metadata and adaptation destinations. A concept capsule
also stores the actual 16,384-bit AEON vector and verifies its exact 8,192-base
projection. `apotheosis restore` restores that saved vector, rather than deriving
a new one from its label. A deliberately changed PAIN vector survived this test.
The native Think Mind has its own recoverable capsule; deleting its working
JSON in an isolated fixture and starting a new JVM recovered and reused the
learned subtraction rule.

Coverage is explicit: these capsules contain component/profile/native state and
artifact references, not every model tensor or all application memories.
Current capsule/evidence paths are machine-local absolute paths; relocatable
imports are not implemented. The reader validates the selected capsule and its
payloads; it does not recursively audit the complete parent history.

## Native creation and codec corrections

The owner's Think implementation parses integer expressions, compares compiled
VM output with an independent evaluator, tests proposed opcode-map changes on
fresh values and retained cases, and saves a successful repair. The integration
proved 14 - 9 repaired ADD to SUB and a new JVM solved 100 - 37 without rediscovering
that repair. Its unsupported prose remains UNVERIFIED. An own-property guard
prevents `recall constructor` from returning an inherited JavaScript function
as a stored fact.

The VM worker compares real interpreter and compiled WASM output and saves the
artifact/hash. The 6 * 7 proof returned 42 in both paths. Legacy source labels
that describe FNV checksums as Ed25519 certificates are not accepted as signatures.
The integrated response states the actual comparison/checksum scope.

Native methods include ternary ledgers/outliers, small neuron/layer fitting,
nearest-prototype updates, source-preserving project templates, numerical affect
dials, local reflexes, byte/DNA codecs and mirrored-genome repair. Their contracts
are in `data/specialists/native-methods.json`; `operation=methods` lists the
worker's available functions. Toy/layer training returns its own local state;
it does not alter a deployed model checkpoint. Imported source methods that
are not allowlisted remain source capabilities, not advertised live tools.

The Enigma bridge calls the actual owner core functions and fixes their framing
at the boundary. New Fraynix Enigma v2 output records payload/body SHA256,
payload length and a rotor identifier digest, uses the correct FNV payload tag,
allocates WASM pages for header plus manifest plus payload, validates WASM
statically and PNG chunk CRCs, and verifies full byte recovery. Wrong rotors,
truncation, corrupted bytes and invalid checksums are rejected before recovered
output is written. Legacy v1 additionally needs an independently known payload
SHA256. Recovered code is never executed. This remains reversible representation
with corruption checks, not authenticated encryption.

## Live memory recovery and persistence corrections

The real learned-state probe exposed a pre-existing destructive interaction:
AkashicRecord skipped a base snapshot above a hard-coded 128 MB threshold, then
saved the small in-memory subset over that base. The initial probe also used a
3 GB test heap and encountered a non-daemon Enteric monitor after main returned.
That run is recorded as failed, not counted as a successful boot or state proof.

The loader now attempts the complete base by default. An explicit resource limit
or load failure defers it without replacing it: new records use a separate pending
overlay. A later full load merges the overlay. An unreadable overlay blocks saving;
an unreadable chain is retained. Record and chain replacements are written to
complete temporary files before replacement. These changes do not implement
multi-process transactions; use one writer and a clean shutdown for checkpoints.
The Enteric monitor now uses a named daemon and its permanent shutdown releases
the scheduler.

Kronos now escapes labels/binding values with the actual JSON serializer, restores
persisted JSON with the strict parser, persists every retained alias rather than
a 100-per-concept serialization sample, and replaces its local snapshot atomically.
Equal-size state snapshots now select the newest timestamp deterministically.
Its existing runtime admission capacities remain separate from persistence.
A two-JVM regression proves quoted/backslash/newline labels and 120 retained
aliases survive. A separate three-JVM test proves deferred base preservation,
pending writes and later merging. Both Enteric return-with-monitor and explicit
shutdown tests terminate normally.

Before recovery, all available live state was archived separately. The verified
October 20 preservation archive contributed 23 older blocks; the current file
contributed 30. All 53 distinct record hashes were retained in the merged file.
The old archive already contained 659 chain references without available records.
The current merged historical chain contains 792 such references. These gaps
remain unresolved: the original chain is retained, and a complete historical
integrity claim would be false. Snapshot checksums and successful current restart
checks establish the available records, not recovery of missing historical data.
The validation record includes the baseline audit and recovery evidence hashes.
The subsequent real app run exited normally with the checked source files and ten original
FASTA hashes unchanged. A fresh JVM restored 64 blocks, 1,479 concepts and
60,000 retained aliases, replayed seven evidence events and added zero duplicate
Kronos bindings. Historical chain verification remains false for the gaps above.
